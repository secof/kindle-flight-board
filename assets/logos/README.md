# Airline Logos Directory

Place high-contrast PNG logo files in this directory named after their 3-letter ICAO airline designators:

Examples:
- `AAL.png` (American Airlines)
- `DLH.png` (Lufthansa)
- `BAW.png` (British Airways)
- `DAL.png` (Delta Air Lines)
- `UAL.png` (United Airlines)
- `AFR.png` (Air France)
- `DEFAULT.png` (Fallback logo for unlisted airlines)

### Recommended Image Specs:
- **Dimensions:** 180x100 pixels (or similar ~ 1.8:1 ratio)
- **Format:** PNG with transparent or white background
- **Style:** High contrast, monochrome or dark grayscale for best e-ink clarity
